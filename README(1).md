Страница размещена в папке public. Файл server.js запускает сервер Express и отдаёт страницы, стили, скрипты и изображения.

Для запуска нужны Node.js и npm. В папке проекта выполните команды:

`npm install`
`npm start`

После запуска откройте http://localhost:3000/ в браузере.

Реализованы маршруты:

GET / — главная страница с прогнозами.
GET /about — отдельная страница с информацией об авторе.
GET /api/status — JSON с временем работы процесса в секундах, памятью процесса (RSS) в МБ, количеством логических процессоров и текущим временем в формате ISO.

Примеры параметров:

http://localhost:3000/api/status?precision=0 — query-параметр precision задаёт число знаков после запятой для времени работы и памяти (от 0 до 3).
http://localhost:3000/api/status/cpuCount — параметр маршрута metric выбирает одну метрику из ответа. Можно также указать uptimeSeconds, memoryUsageMB или timestamp.

Файл manifest.json задаёт название приложения, цвета и иконки 192×192 и 512×512. Файл pwa.js регистрирует service worker. Он сохраняет страницы и статические файлы в кеше браузера, чтобы главная страница и /about открывались без сети после первого посещения. Динамические данные /api/status без работающего сервера недоступны.

Для проверки офлайн-режима откройте сайт через localhost и один раз перезагрузите страницу при работающем сервере. Затем в инструментах разработчика включите режим Offline и обновите главную или страницу /about. Не открывайте index.html как файл: маршруты и service worker работают через сервер.

Установку PWA на компьютере проверяйте в Chrome или Edge через значок установки в адресной строке. В Firefox для компьютера установка по манифесту без расширения не поддерживается.
